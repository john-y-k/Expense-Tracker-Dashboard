# Expense-Tracker-Dashboard
A responsive personal finance dashboard built with React and TypeScript that allows users to track expenses, analyze spending habits, and manage financial data through an interactive interface.

The application provides expense management features, data visualization, CSV import/export, and persistent storage for a seamless user experience.

# Features
### Expense Management
- Add, edit, and delete expenses
- Categorize expenses by type
- Assign dates to expenses
- Validate expense entries before submission
- Persist data using browser LocalStorage

### Dashboard Analytics
- View total spending
- View monthly spending totals
- Track number of transactions
- Display top spending categories
- Visualize expenses with interactive charts

### Data Visualization
- Category spending breakdown using pie charts
- Monthly spending trends using bar charts
- Responsive chart layouts

### Transaction Management
- Sort expenses by:
   - Newest date
   - Highest amount
   - Lowest amount
- Filter expenses by category
- View transactions in a structured table

### CSV Support
- Import expense data from CSV files
- Export expenses into CSV format

# Installation and Setup
- Clone the repository:
    git clone https://github.com/john-y-k/expense-tracker.git
- Navigate into the project directory:
    cd expense-tracker-dashboard
- Install dependencies:
    npm install
- *If found vulnerabilities and prompted, run:
    npm audit fix
- Start the development server:
    npm run dev
Open the local development URL provided by Vite.
